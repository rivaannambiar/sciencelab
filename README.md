## 🧬 THE MISSION

Science Lab is an interactive educational website designed to make science feel less like memorizing a textbook and more like **actually being inside a laboratory.**

Students don't just read about science.

They:

> 🔐 Crack an Element Vault
> ⚛️ Explore 118 elements
> 🏭 Build and repair molecules
> ⚡ Watch electrons jump between energy levels
> 🧠 Solve scientific challenges

Explore every element.

**Includes all 118 elements**, with:

* Atomic number
* Symbol
* Name
* Atomic mass
* Electron configuration
* Element categories
* Interactive inspector
* Search system

**Plus:**
Lanthanides & actinides are displayed separately below the main table.

<tr>
<td>

### 🏭 MOLECULAR FACTORY

Build and repair chemical reactions.

Students work with:

* Molecules
* Chemical formulas
* Chemical equations
* Balancing reactions
* Chemical structures

Example:

```text
H₂ + O₂ → H₂O

        ↓

2H₂ + O₂ → 2H₂O
```

</td>

<td>

### ⚡ ELECTRON ARCADE

See electrons in action.

Watch an electron:

```text
LOW ENERGY
    │
    │  ⚡ ENERGY ABSORBED
    ▼
HIGH ENERGY
    │
    │  ✨ PHOTON RELEASED
    ▼
LOW ENERGY
```

The simulation lets students visually see electrons move between energy levels.

# 💡 DESIGN PHILOSOPHY

Science Lab follows one simple idea:

> **Don't just tell students how science works. Let them interact with it.**

Instead of:

```text
READ → MEMORIZE → TEST
```

Science Lab aims for:

```text
EXPLORE → EXPERIMENT → SOLVE → DISCOVER
```
