# ⚛️ Science Lab

> An interactive science-learning website built for Teacher's Day.

Science Lab turns basic chemistry and physics concepts into interactive missions, challenges, quizzes, and simulations.

Instead of just reading about science, students can **experiment, solve problems, inspect elements, build molecules, and explore electrons.**

---

## 🚀 Features

### 🏠 Home
The central hub for the Science Lab.

- Introduction to the Science Lab
- Science missions
- Mission progress tracking
- Example science problems
- Navigation to all interactive activities

---

### 🔐 Element Vault

A chemistry challenge where students become science investigators.

Students learn about:

- Atoms
- Protons
- Neutrons
- Electrons
- Atomic number
- Elements
- Electron configuration
- Aufbau filling order

The vault contains multiple-choice challenges with:

- ✅ Correct-answer detection
- ❌ Incorrect-answer feedback
- 🏆 Score system
- 🔥 Streak system
- 🔓 Vault unlock animation
- 📚 Explanations for every question

---

### 🧪 Interactive Periodic Table

Explore all **118 elements** through an interactive periodic table.

Each element displays:

- Atomic number
- Symbol
- Name
- Category
- Atomic mass
- Electron configuration

Clicking an element opens an **Element Inspector** showing its atomic structure and information.

The periodic table also includes:

- 🔎 Element search
- 🟦 Metals
- 🟩 Nonmetals
- 🟨 Metalloids
- 🟪 Noble gases
- Lanthanides
- Actinides

The lanthanides and actinides are displayed separately below the main periodic table, just like a standard periodic-table layout.

---
